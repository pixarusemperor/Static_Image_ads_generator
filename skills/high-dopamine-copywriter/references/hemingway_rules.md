# The Hemingway Readability Rules for High-Dopamine Ads

High-dopamine advertising relies on effortless cognitive processing. If reading an ad requires conscious intellectual effort, the user immediately leaves the post. 

The copy must read like butter down a greasy chute: effortless, rhythmic, and impossible to get stuck on.

---

## 1. The Flesch-Kincaid Mathematical Formula

Readability is evaluated using the standardized Flesch-Kincaid Grade Level formula:

$$\text{FKGL} = 0.39 \left( \frac{\text{total words}}{\text{total sentences}} \right) + 11.8 \left( \frac{\text{total syllables}}{\text{total words}} \right) - 15.59$$

### Benchmark Targets
- **New York Times / WSJ:** Grade 10–12
- **Standard Corporate B2B Ads:** Grade 9–11 ❌ *(Fails: Triggers cognitive fatigue)*
- **High-Dopamine Ad Standard:** **Grade 3.5 – 5.0** ✅ *(Optimal: Zero friction)*

---

## 2. Sentence Length & Cadence Rules

1. **The 12-Word Ceiling:**
   - Average sentence length across the copy must remain under **10 words**.
   - No single sentence may exceed **14 words**.
2. **One Sentence Per Line:**
   - Never combine two thoughts into a compound sentence separated by semicolons or convoluted conjunctions.
   - Separate every sentence with a line break (`\n\n`).
3. **Pacing Variation:**
   - Alternate 3-word punches with 9-word narrative sentences to establish a musical rhythm:
     - *"They are wrong."* (3 words)
     - *"It happens in client chat channels every single Tuesday."* (9 words)
     - *"No manual timesheets."* (3 words)

---

## 3. Syllable Pruning & The Simplification Dictionary

Multi-syllable Latinate words must be ruthlessly replaced with punchy Germanic roots (1–2 syllables):

| Corporate / Complex Word (Grade 9+) | High-Dopamine Replacement (Grade 3–5) |
| :--- | :--- |
| Utilize | Use |
| Facilitate | Help / Run |
| Implementation | Setup |
| Substantial | Huge / Big |
| Comprehensive | Complete / Full |
| Revolutionize | Flip / Change |
| Discontinue | Stop / Drop |
| Discrepancy | Gap / Error |
| Compensation | Pay / Cash |
| Sufficient | Enough |
| Commencing | Starting |
| Methodologies | Steps / Ways |
| Eradicate | Wipe out |
| Optimized | Tuned / Peak |
| Revenue generation | Making cash |

---

## 4. Mobile Eye-Tracking Rhythm

When a user views an ad on an iPhone or Android screen, their eyes scan in an **F-shape pattern**:
- If the first 4 words of a paragraph do not offer an immediate visual hook, the rest of the paragraph is skipped.
- Paragraphs with 3+ lines of text appear as a dense block of gray ink on mobile displays.
- By enforcing 1 sentence per paragraph with generous whitespace, the thumb continues scrolling gently while the brain absorbs each micro-thought effortlessly.
