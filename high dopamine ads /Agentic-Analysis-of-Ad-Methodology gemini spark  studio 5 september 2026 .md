#### 1. The Post-Click "Scent / Bridge" Disconnect

* **The Failure Mode:** The video emphasizes opening a massive curiosity gap (e.g., holding a mysterious glowing USB stick with the headline *"This client hack feels illegal"*). However, if the click leads to a standard corporate landing page or generic booking form, the conversion drops to zero and bounce rates spike above 90%.
* **What Was Missed:** A dedicated **Bridge & Advertorial Congruence** step. The skill pipeline must generate the exact post-click landing page headline, hero mechanism, and introductory narrative that immediately acknowledges and satisfies the specific curiosity hook before transitioning into the sales pitch.

#### 2. Deterministic Image Assembly vs. Generative Hallucination

* **The Failure Mode:** Relying on generative image models (DALL-E, Midjourney, Imagen) to draw the red circle, hand-drawn arrow, tabloid breaking-news bar, and text directly onto the canvas results in garbled typography, misplaced arrows, and hallucinated layouts.
* **What Was Missed:** Decoupling **Image Generation** from **Image Assembly**. In the Anthropic skill standard, skills should leverage deterministic tools (Python scripts using `Pillow`, `OpenCV`, or SVG generators) to programmatically calculate bounding boxes, stamp tabloid text with exact color-splits (White/Yellow), inject hand-drawn jitter arrows, and overlay authentic iOS/Android notification badges.

#### 3. The Abstract Niche-to-Object Mapping Problem

* **The Failure Mode:** Sabri's physical examples are straightforward: holding a physical USB drive, showing an Iron Neck brace, or demonstrating purple teeth serum. But for B2B SaaS, tax accounting, legal consulting, or agency services, generative models default to corporate stock photography (handshakes, blue suits, glass offices).
* **What Was Missed:** An explicit **Niche-to-Mystery-Object Matrix** that translates intangible mechanisms into tangible, tactile, curiosity-inducing physical props (e.g., redacted government forms with neon highlighters, thermal printout receipts, microscope slides, microchips, confidential folders).

#### 4. Meta Policy Moderation vs. Tabloid Sensationalism

* **The Failure Mode:** Words like *"Feels Illegal"*, *"Shocking Warning"*, *"Secret Hack"*, and extreme claims violate Meta's policies on **Sensational Systems**, **Unrealistic Results**, and **Circumventing Systems**. Furthermore, calling out user attributes directly triggers immediate ad rejection.
* **What Was Missed:** A **Policy Safe-Harbor Translation Layer**. The skill must automatically re-encode raw tabloid hooks into editorial, journalistic, or first-person case-study formats (e.g., shifting from *"This feels illegal"* to *"Why industry whistleblowers are questioning this 2026 data protocol"*).

#### 5. The "Positive Honey vs. Vinegar" Polarity Constraint

* **The Failure Mode:** Inexperienced copywriters gravitate toward negative fear-mongering (*"Don't lose your business in 2026"*).
* **What Was Missed:** Sabri explicitly proves that positive hooks promising an outsized tangible benefit outpull negative avoidance hooks 8 out of 10 times (*"How to add 90–480 inbound clients"* vs. *"Stop running out of leads"*). The copywriting skills must enforce a positive benefit bias.

### Part 3: Deterministic Code Implementation (The Image Assembly Engine)

To eliminate generative hallucination of arrows, circles, and typography, below is the production-ready script specification for `skills/image-assembly-engine/scripts/assemble_ad.py`:

```python
"""
assemble_ad.py - Programmatic Compositor for Hyper-Dopamine Facebook Creatives
Handles:
1. Aspect ratio fitting (1:1 and 4:5 mobile feed safety)
2. Imperfect hand-drawn markup (Jittery Red Circle & Arrow)
3. Tabloid news banner with White/Yellow chromatic font split
4. Authentic ISO grain injection & background desaturation
"""

import math
import random
from PIL import Image, ImageDraw, ImageEnhance, ImageFilter, ImageFont


def add_hand_drawn_circle(
    draw, center, radius, color=(235, 15, 15, 255), width=6
):
  """Draws an imperfect, slightly jittered circle to mimic human phone markup."""
  cx, cy = center
  points = []
  steps = 60
  for i in range(steps + 5):  # Overlap slightly at the end
    angle = (i / steps) * 2 * math.pi
    # Inject Perlin-like random radial noise
    jitter = random.uniform(-radius * 0.04, radius * 0.04)
    r = radius + jitter
    x = cx + r * math.cos(angle)
    y = cy + r * math.sin(angle)
    points.append((x, y))

  for i in range(len(points) - 1):
    draw.line([points[i], points[i + 1]], fill=color, width=width)


def add_hand_drawn_arrow(
    draw, start, end, color=(235, 15, 15, 255), width=6
):
  """Draws an imperfect curved arrow pointing from start to end."""
  sx, sy = start
  ex, ey = end

  # Compute midpoint with curve offset
  mid_x = (sx + ex) / 2 + random.uniform(-20, 20)
  mid_y = (sy + ey) / 2 + random.uniform(-20, 20)

  # Quadratic Bezier approximation
  curve_points = []
  for t in [i / 20.0 for i in range(21)]:
    x = (1 - t) ** 2 * sx + 2 * (1 - t) * t * mid_x + t**2 * ex
    y = (1 - t) ** 2 * sy + 2 * (1 - t) * t * mid_y + t**2 * ey
    curve_points.append((x, y))

  for i in range(len(curve_points) - 1):
    draw.line([curve_points[i], curve_points[i + 1]], fill=color, width=width)

  # Draw Arrowhead
  angle = math.atan2(ey - mid_y, ex - mid_x)
  arrow_len = 24
  spread = math.pi / 6
  p1 = (
      ex - arrow_len * math.cos(angle - spread),
      ey - arrow_len * math.sin(angle - spread),
  )
  p2 = (
      ex - arrow_len * math.cos(angle + spread),
      ey - arrow_len * math.sin(angle + spread),
  )

  draw.line([end, p1], fill=color, width=width)
  draw.line([end, p2], fill=color, width=width)


def render_tabloid_banner(
    base_img,
    white_text,
    yellow_text,
    banner_height_ratio=0.18,
    bg_color=(15, 15, 15, 235),
):
  """Draws a tabloid news banner across the lower section with chromatic split."""
  width, height = base_img.size
  banner_h = int(height * banner_height_ratio)
  banner_y = height - banner_h

  banner_overlay = Image.new("RGBA", (width, banner_h), bg_color)
  base_img.paste(banner_overlay, (0, banner_y), banner_overlay)

  draw = ImageDraw.Draw(base_img)
  font_size = int(banner_h * 0.38)
  try:
    font = ImageFont.truetype("assets/fonts/Montserrat-ExtraBold.ttf", font_size)
  except IOError:
    font = ImageFont.load_default()

  # Calculate bounding boxes and center text
  full_text = f"{white_text} {yellow_text}"
  bbox = draw.textbbox((0, 0), full_text, font=font)
  text_w = bbox[2] - bbox[0]
  start_x = max(20, (width - text_w) // 2)
  start_y = banner_y + (banner_h - (bbox[3] - bbox)) // 2

  draw.text((start_x, start_y), white_text, fill=(255, 255, 255, 255), font=font)
  w_bbox = draw.textbbox((0, 0), white_text + " ", font=font)
  draw.text(
      (start_x + (w_bbox[2] - w_bbox[0]), start_y),
      yellow_text,
      fill=(255, 229, 0, 255),
      font=font,
  )


def inject_sensor_noise(image, factor=0.08):
  """Adds camera ISO grain to strip away synthetic AI sheen."""
  grain = Image.effect_noise(image.size, factor * 255).convert("L")
  grain_rgba = Image.new("RGBA", image.size)
  grain_rgba.paste((255, 255, 255, int(factor * 255)), (0, 0), mask=grain)
  return Image.alpha_composite(image.convert("RGBA"), grain_rgba)
```
